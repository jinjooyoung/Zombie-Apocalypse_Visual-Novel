검사

위쪽 ‘저장’을 누르면 대사가 게임 폴더의 Dialog/Dialog.csv로 저장돼요. 저장할 때마다 ID는 흐름 순서대로 새로 매겨져요.

캐릭터

이름을 누르면 ‘한글 이름/EnglishName’ 형식으로 고칠 수 있어요. 한글은 게임에 표시되는 이름, 영문은 폴더 이름이에요.
표정 칸을 누르면 이미지를 골라 둬요. ‘저장’을 누를 때 Characters/영문이름/표정코드.png로 게임 폴더에 복사돼요.
캐릭터는 배경과 같은 16:9 화면 전체에 겹쳐 떠요. 머리 위와 양옆은 비운 투명 PNG로 그리면 되고, 날개·파티클도 화면 어디에나 그릴 수 있어요. 1920 × 1080처럼 크게 그릴수록 선명해요. 점선은 대사창이 덮는 자리예요. 움직이는 GIF·WebP·APNG도 넣을 수 있어요.

UI

왼쪽은 미리보기예요. 오른쪽 ‘화면 요소’에서 대사창·이름표 같은 요소를 눌러 슬라이더로 위치와 크기를 바꾸고, ‘리소스 선택’으로 이미지를 골라요.
글꼴과 글자 크기·색도 오른쪽 창에서 정해요. ‘저장’을 누르면 이미지는 UI 폴더에, 배치와 글자 설정은 UI/Layout.json에 저장돼요.

배경

이름은 ‘배경 이름/BackgroundName’ 형식이에요. 영문 이름이 파일 이름이 되고, 대사에서는 bg_영문이름 으로 골라요.
이미지를 누르면 파일을 골라 두고, ‘저장’을 누를 때 Backgrounds/영문이름.png로 복사해요. 16:9 비율이면 1920 × 1080처럼 더 커도 돼요. 움직이는 GIF·WebP·APNG도 넣을 수 있어요.

엔딩

엔딩을 만들고 이름을 ‘엔딩 제목/ENDINGNAME’ 형식으로 정해요. 대사 탭의 엔딩 블럭에서 이 엔딩을 고르면, 엔딩 화면에 제목과 컷씬이 나와요.
컷씬은 16:9 이미지(PNG·움직이는 GIF·WebP·APNG)로, ‘저장’을 누르면 Endings/영문이름.png 등으로 복사돼요. 컷씬 없이 써도 돼요. 엔딩 화면의 글자·버튼 위치는 UI 탭에서 바꿔요.

사운드

이름은 ‘사운드 이름/SoundName’ 형식이에요. 음표를 누르면 소리 파일을 골라 두고, ‘저장’을 누를 때 Sounds/BGM 또는 Sounds/SFX 폴더에 복사해요.
BGM의 ★는 메인 BGM(대사에서 MAIN)이에요. 아이폰까지 생각하면 mp3를 추천해요.
